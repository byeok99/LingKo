# 제품과 사용자 흐름

LingKo는 한국어 학습자가 문장을 듣고 녹음한 뒤 발음 피드백과 입 모양 가이드를 통해 다시 연습하는 모바일 서비스입니다.

## 연습 흐름

1. 가입 시 동의를 받은 뒤 소셜 로그인을 진행하고, 로그인 성공 후 서버에 동의를 기록합니다. 세션 복원 시에도 현재 문서 버전의 동의 상태를 확인합니다.
2. 추천 문장을 고르거나 자유 문장을 입력합니다.
3. 원문에서 계산된 표준 발음·로마자 가이드와 TTS를 확인합니다.
4. WAV 녹음을 업로드하고 평가 작업을 등록합니다.
5. 처리 상태를 조회한 뒤 문장·단어 평가와 음절 가이드를 확인합니다.
6. 기록에서 재연습하거나 문장을 저장합니다.

재연습은 과거 평가의 발음 snapshot을 정답으로 재사용하지 않고 현재 변환 규칙으로 문장을 다시 준비합니다.

## 추천 콘텐츠

기본 데이터는 총 48개이며 FOOD, DAILY, TRAVEL, STUDY, WORK, HEALTH 각 8개입니다. 기존 문장의 ID와 참조를 보존하면서 Flyway V22로 27개를 추가했습니다. 별도로 등록한 콘텐츠는 기본 개수와 구분합니다.

## 평가 정보의 의미

- 문장·단어 점수는 음성 평가 제공자의 응답을 검증해 사용합니다.
- 초성·중성·종성 가이드는 발음을 설명하는 학습 자료이며 그 자체가 사용자의 음절 점수는 아닙니다.
- 입·혀 가이드는 기존 도해로 주요 조음 위치와 자세 변화를 보여주는 참고 자료입니다. 성대·연구개·기류와 실제 발성 기관의 연속 움직임을 정밀하게 재현하는 의료·음성학 시뮬레이션은 아닙니다.
- 없는 음절 점수는 `null`로 유지합니다. 0점이나 주변 단어 점수로 추정하지 않습니다.
- 영상 생성에 실패하면 사용 가능한 이미지 가이드로 대체할 수 있습니다.

## 평가 기회

최대 5회를 보유하며 5회 미만일 때 서버 기준 1시간마다 1회 충전합니다. 자정 초기화 방식이 아닙니다. 평가 작업 생성 시 예약하고 성공하면 확정, 실패하면 복구합니다. 광고 보상은 서버가 SSV를 검증한 뒤 지급하며 최대 보유량과 자연 충전 시각 규칙을 지킵니다.

## 구현 설명의 범위

소셜 인증, 플랫폼 권한, 외부 서비스는 앱·서버 코드뿐 아니라 해당 환경의 설정에 의존합니다. 구현 문서는 개별 기기의 실행 성공이나 현재 운영 배포 버전을 대신하지 않습니다.
