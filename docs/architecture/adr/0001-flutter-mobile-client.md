# ADR-0001 Flutter 모바일 클라이언트

- 상태: 승인
- 날짜: 2026-07-21

## 배경

iOS와 Android에서 동일한 발음 연습 흐름, 녹음, API 연동, 로그인 UI를 제공해야 합니다.

## 결정

Flutter를 모바일 클라이언트로 사용하고 플랫폼별 권한·빌드 설정만 Android/iOS 네이티브 프로젝트에서 관리합니다.

## 대안

- Android·iOS 네이티브 앱 별도 개발
- 반응형 웹 또는 PWA
- React Native

## 결과

- 하나의 Dart 코드베이스로 주요 UI와 API 흐름을 공유합니다.
- 마이크, Google 로그인, 보안 저장소는 플랫폼 설정과 실기기 검증이 필요합니다.
- 상태와 화면 규모가 커지면 현재 `StatefulWidget` 중심 구성을 재검토합니다.
