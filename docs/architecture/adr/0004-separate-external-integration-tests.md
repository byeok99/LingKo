# ADR-0004 외부 통합 테스트 분리

- 상태: 승인
- 날짜: 2026-07-21

## 배경

Azure Speech, Replicate, S3, FFmpeg를 호출하는 테스트는 비밀값, 비용, 네트워크, 실행시간에 의존합니다. 이를 일반 테스트와 함께 실행하면 로컬 개발과 PR 검증이 불안정해집니다.

## 결정

- `test`: 단위·Controller·Repository 테스트
- `integrationTest`: 외부 네트워크를 호출하지 않는 통합 테스트
- `externalIntegrationTest`: `external` 태그가 붙은 실제 외부 연동 테스트

## 결과

- 기본 검증은 비밀값 없이 반복 가능해집니다.
- 외부 계약 변경은 일반 CI만으로 발견하지 못할 수 있으므로 수동·야간·릴리스 전 실행이 필요합니다.
- 외부 테스트 계정과 비용 한도를 별도로 관리해야 합니다.
