# ADR-0003 Flyway 스키마 관리

- 상태: 승인
- 날짜: 2026-07-21

## 배경

사용자, 평가 기록, 음절 결과, 학습 설정, 평가 기회의 스키마 변경을 환경마다 동일하게 적용해야 합니다.

## 결정

Flyway 버전 SQL을 스키마 변경의 기준으로 사용하고 운영 환경에서 Hibernate 자동 DDL 변경을 사용하지 않습니다.

## 대안

- `ddl-auto=update`
- 수동 SQL 적용
- Liquibase

## 결과

- 변경 이력이 코드와 함께 보존됩니다.
- 적용된 마이그레이션은 수정하지 않고 보정 파일을 추가해야 합니다.
- 애플리케이션 롤백을 고려한 하위 호환 마이그레이션이 필요합니다.
