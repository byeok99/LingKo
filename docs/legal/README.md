## 구현이 선행되어야 하는 항목

문서에 적혀 있지만 **아직 코드에 없는 것들입니다. 이대로 공개하면 사실과 다른 고지가 됩니다.**

| 문서 기재 내용 | 현재 상태 |
|---|---|
| 가입 시 필수 2건·선택 1건 동의 | **구현 완료.** 앱 화면에서 선택한 값을 인증 사용자에게 귀속해 `POST /api/legal/consent`로 저장하고, 복원 세션도 `GET /api/legal/consent`에서 현재 버전 미동의를 확인하면 Home 대신 동의 화면을 표시한다 |
| 약관·처리방침 전문 열람 | **구현 완료.** 백엔드가 `GET /legal/terms`, `GET /legal/privacy`로 서빙하고(`?lang=ko\|en`), 앱의 동의 화면과 Profile이 이 URL을 인앱 WebView로 연다. 스토어 심사에 제출할 공개 URL도 이 주소를 쓴다 |
| 만 16세 이상 | 동의 화면에 안내 문구만 있고 실제 연령 확인 수단이 없다 |
| Apple 로그인 | **iOS 앱·Backend token 검증 코드와 Apple Developer App ID capability·development provisioning 설정 완료.** Apple 이메일 relay 주소는 검증된 token email로 저장한다. 실제 로그인 E2E와 authorization code 기반 token revocation은 출시 전 남아 있다 |
| Google AdMob 광고 | **SSV 검증 구현 완료.** 앱이 1회성 session token을 `customData`로 전달하고 Backend가 Google 서명·광고 정책·전역 transaction을 검증한 뒤 지급한다. iOS 운영 App/Rewarded Ad Unit ID와 서버 allowlist는 설정됐으며, AdMob console의 공개 HTTPS callback 설정 확인과 실제 광고 E2E가 남아 있다 |
| CMP(EEA 사전 동의) · ATT(iOS) | Google UMP의 consent update·필수 form·privacy options 재진입을 연결했다. ATT prompt는 미구현 |
| 앱 내 설정 화면 | Profile에서 이용약관·개인정보처리방침을 공개 URL로 열고 회원 탈퇴를 제공한다. 광고 개인정보 설정과 문의 행은 제거했으며 문의는 정책 문서의 이메일을 이용한다 |
| 마케팅 수신 동의의 서버 저장 및 철회 | 가입 시 선택값의 서버 저장은 구현 완료. Profile에서 이후 철회·변경하는 기능은 미구현 |
| 휴면 전환·사전 통지·자동 삭제 | 백엔드 배치 없음 |

동의 화면은 문서 버전(`consentDocumentVersion`)을 함께 기록합니다. **`docs/legal/`의 시행일을 바꾸면 `app/lib/models/consent_selection.dart`와 `backend`의 `LegalConsentPolicy.CURRENT_DOCUMENT_VERSION`을 같은 작업에서 올려야** 모든 로그인·복원 세션에 재동의를 요구할 수 있습니다.

## 문서를 고칠 때

이 폴더의 `*.md`가 원본이고, 서빙되는 사본이 `backend/src/main/resources/legal/`에 있습니다. Docker 빌드 컨텍스트가 `backend/`만 포함해 빌드 시점에 이 폴더를 참조할 수 없어 사본을 둡니다.

1. `docs/legal/`의 문서를 고칩니다.
2. 같은 파일을 `backend/src/main/resources/legal/`로 복사합니다.
3. 시행일을 바꿨다면 앱의 `consentDocumentVersion`과 백엔드의 `LegalConsentPolicy.CURRENT_DOCUMENT_VERSION`을 함께 올립니다.

복사를 빠뜨리면 `LegalDocumentSourceSyncTest`가 실패합니다. 이용자에게 옛 약관이 보이는 상황을 막기 위한 장치입니다.

## 변호사 검토가 필요한 판단

| 판단 | 근거 | 위험 |
|---|---|---|
| 음성을 민감정보·생체정보로 보지 않음 | 개인 식별 목적이 아닌 발음 정확도 측정 목적. GDPR Art. 4(14)는 "고유하게 식별할 목적"의 처리만 생체정보로 봄 | **미국 일리노이 BIPA는 "voiceprint"를 목적 한정 없이 생체 식별자로 열거하고, 규모 기준 없이 적용되며 사적 소송권이 있습니다.** 미국 이용자를 받기 전 미국 변호사 검토 필요 |
| 발음 점수는 자동화된 결정이 아님 | 권리·의무에 중대한 영향이 없는 학습 참고 정보 | 낮음 |
| 무료 서비스 책임을 경과실 상한으로 제한 | 약관규제법과 Directive 93/13/EEC의 강행규정 유보 문구 포함. 전면 면책이 아니라 상한 방식 | 조항 무효 판단 여지는 남음 |
| Google에 대한 광고 데이터 전달을 위탁+국외이전으로 기재 | AdMob은 Google이 자체 목적으로도 처리할 수 있어 지역에 따라 제3자 제공·판매/공유로 볼 여지가 있음 | 미국 주법상 "Share" 해당 시 Do Not Sell/Share 링크가 별도로 필요할 수 있음 |

## 관할별 문서를 두지 않은 데 따른 한계

공통 1세트 방식은 운영이 단순하지만, 관할별 전용 문서에 있던 다음 항목은 담기지 않았습니다. 해당 시장에 본격 진출할 때 재검토하세요.

- **일본 APPI**: 第32条 공표 6항목, 第28条 외국 제3자 제공의 이전처 국가별 제도 설명, 苦情申出先 명기, 開示請求 수수료
- **미국 CCPA/CPRA**: Do Not Sell or Share 링크, Notice at Collection, 7대 권리 개별 기재. 현재 적용 기준(매출 USD 26.6M / CA 거주자 10만 명 / 판매 매출 50%) 미달이라 생략했습니다
- **EU DSA**: 평이한 언어 요약, 콘텐츠 제한 사유 통지
